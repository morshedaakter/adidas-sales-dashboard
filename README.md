## Adidas Sales Analysis Dashboard - Power BI

This project is a comprehensive **Sales Analysis Dashboard** built using **Power BI**, focused on Adidas sales data.  
The dashboard provides valuable insights into sales trends, performance by region, product category, and top retailers.

---

## 📊 Key Highlights:

- **Total Sales:** $900M
- **Operating Profit:** $332M
- **Units Sold:** 2 Million
- **Price per Unit:** $45
- **Operating Margin:** 42%

---

## 📈 Visuals Included:

- **Monthly Sales Trend (Line Chart)**
- **Regional Sales Distribution (Donut Chart)**
- **Top Products & Retailers (Bar Charts)**
- **Sales by Geography (Map Visual)**
- **Dynamic Filters for Region & Date**

---

## 📁 Tools Used:

- Power BI
- Sample Adidas Sales Dataset
- DAX for measures (Profit, Margin, etc.)
- Data Modeling and Interactive Slicers
